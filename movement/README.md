# Synthia Movement Layer Assembly v0.1.0

First vertical assembly pass for the current Synthia state space.

This package does **not** create a replacement Synthia. It joins existing Movement-capable mechanisms from the supplied lineages and keeps source conflicts visible.

## Current vertical spine

```text
Movement
  -> Evolution
      -> Being
          -> Design
              -> Space emerges through interplay
```

Movement currently resolves as:

```text
Movement -> Energy -> WHEN -> Axiom
```

Its preserved quality chain is:

```text
Energy -> Creation -> Seeing -> Landscape -> Environment
```

Movement is the current **measurement + naming** layer. Its live assembly uses:

```text
R21.22 64-locus state space
  + R21.22 local coordinate measurement
  + R21.22 ContentGraph naming/dependency
  + v0.5.6 reversible Movement transport
  + Reciprocal Life Movement constraints
  + existing line/bigram/trigram/hexagram fragment structures
  = Movement layer assembly
```

## Swarm release

Each Movement quality can release a swarm view over a Gate's same six underlying line positions:

```text
line positions: [1 2 3 4 5 6]

3 bigrams:  [1 2] [3 4] [5 6]
2 trigrams: [1 2 3] [4 5 6]
1 hexagram: [1 2 3 4 5 6]
```

The six relational structures coexist. They do not replace or duplicate the six line states.

Connection reach is carried separately as an optional meter-scale value. This allows attometer/femtometer/picometer-scale reach to be assigned later without changing the 3+2+1 topology.

## Source conflicts intentionally retained

Historical packages disagree on interrogatives. R21.22 says Movement=`What`; an older Kimi constants file says Movement=`Where`; the current project placement is Movement=`When`. The assembly uses the current placement at its boundary and leaves the donor files unchanged.

The Kimi `Movement = reverse` sequence is explicitly labeled unconfirmed in its own source. It is preserved as provenance and is not promoted to the governing Movement order here.

Several older runtimes implement Space as a fifth peer cell. That implementation remains present in the vendor source; the current assembly exposes four primary dimensions and emergent Space.
