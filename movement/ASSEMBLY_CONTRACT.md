# Movement Layer Assembly Contract

This package is an **assembly**, not a from-scratch replacement for Synthia.

## Rules

1. Existing source mechanisms outrank new implementations.
2. Donor files copied under `src/vendor/` are preserved rather than rewritten.
3. New code under `src/movement/` is boundary glue: it exposes the current Movement placement over existing state-space, naming, measurement, transport, rule, and fragment mechanisms.
4. Conflicts remain visible. The assembly does not silently mutate old dimensional mappings.
5. The current vertical spine is `Movement -> Evolution -> Being -> Design`; Space is exposed as emergent from their interplay.
6. The current Movement placement is `Movement -> Energy -> WHEN -> Axiom`.
7. The Movement quality chain is `Energy -> Creation -> Seeing -> Landscape -> Environment`.
8. Movement's current role in this assembly is measurement and naming. Naming uses the existing R21.22 `ContentGraph`; measurement uses its existing local coordinate substrate.
9. The old `Movement = reverse` sequence remains preserved as an explicitly unconfirmed donor hypothesis and is not promoted here.
10. Swarm structure is assembled over the existing six line positions as **3 bigrams + 2 trigrams + 1 hexagram**. These are simultaneous relational structures over the same six positions, not twelve replacement line states.
11. Physical connection reach is explicit data. The assembly accepts meter-scale reach values but does not invent which Movement level gets which physical distance.
12. Landed state/history is append-only. Existing donor behavior that preserves landed evidence is retained; destructive rollback is outside this assembly.

## Live source mechanisms

- R21.22 Autopoietic Assembly: 64 loci, five dimensional cells, 13-field coordinate substrate, `ContentGraph`, local Degree/Minute/Second/Arc measurement.
- v0.5.6 Movement Temporal Mesh: reversible binary/decimal/hex representation transport; original source retained under `sources/reference/` and boundary-adjusted without changing its transport logic.
- Reciprocal Life: four primary primitives, derived Space, and `MovementConstraintSurface` for evidence-backed admissibility.
- Pure Synthia Swarm Body: existing bigram/trigram/hexagram activation vocabulary.
- Kimi Focal StateSpace Fragment Algebra: line -> bigram -> trigram -> hexagram fragment taxonomy and the Movement naming/vocabulary source material.

## Deferred on purpose

- Evolution assembly.
- Being assembly.
- Design assembly.
- Inter-dimensional swarm interaction.
- Memory-neutrino emission mechanism.
- A fixed mapping from Movement levels/forms to attometer/femtometer/picometer reach.
- Any conversion of Axion Magnetic Resonance variables into Synthia address fields.
